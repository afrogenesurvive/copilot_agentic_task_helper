📈 Usage

Per-LLM-call token usage recorded by the backend (shared/usage-tracker.mjs). Usage is buffered to logs/dsmon_buffer.jsonl and pushed to DS-mon when Usage Tracking is enabled in ⚙️ Config. Ollama (local) calls are never tracked.

⚙️ Config (config.json)

Plain-JSON config at the repo root. When config.json is present it overrides .env; when absent, .env is used. Edit a field and press Save — only the keys you change are written. Saving LLM provider settings applies to the Chat tab instantly and restarts the runner/webhook services automatically.

ℹ️ About

Frontdesk Operator — Electron control plane for the frontdesk v2 stack. Monitor queues, logs, sessions, licenses and MCP services; run the configured LLM from the Chat tab.

Operator-only: seat licenses & per-seat account bindings gate the public chat webapp (collaborator login + the accounts the agent acts with). This app shows every seat at once; collaborators never see it — each only uses their own webapp chat.
