Seat → account bindings

Loading…

Connect a Google account or set a Trello key/token per seat. The agent uses these when acting on behalf of that seat. Spawn MCP launches dedicated MCP instances bound to the seat's accounts (instead of the shared VS Code ones).

Operator-only: this view shows all seats at once. Seats & bindings gate the public chat webapp (login + which accounts the agent uses for that seat); collaborators never see this app — each only uses their own webapp chat.

Usage

Per-LLM-call token usage recorded by the backend (shared/usage-tracker.mjs). Usage is buffered to logs/dsmon_buffer.jsonl and pushed to DS-mon when Usage Tracking is enabled in Config. Ollama (local) calls are never tracked.

Config (config.json)

Plain-JSON config at the repo root. When config.json is present it overrides .env; when absent, .env is used. Edit a field and press Save — only the keys you change are written. Saving LLM provider settings applies to the Chat tab instantly and restarts the runner/webhook services automatically. Settings are grouped into tabs; the filter box searches every tab at once, for when you know the key name but not the section it lives in.
