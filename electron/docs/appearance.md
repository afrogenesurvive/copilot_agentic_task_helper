# 🎨 Appearance

The Appearance tab controls the app's color theme.

## Theme options

- **☀️ Light**
- **🌙 Dark**
- **🌑 System** — follows macOS: the native window chrome and this dashboard both update when the
  OS theme changes.

Click an option to apply it immediately. The choice is saved to `APPEARANCE_THEME` in config
(`config.json` or `.env`) and is remembered next launch.

## Notes

- The same setting can also be edited as a field in ⚙️ Config → Appearance section.
- Choosing **System** uses the OS preference live — toggling dark mode in macOS updates the app
  without reopening it.
